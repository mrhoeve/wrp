## Project status: maintenance ending

This is planned to be the final WRP release. The repository is intended to be archived unless users indicate that continued maintenance is needed. Once archived, routine updates and security fixes will stop.

If you use WRP or would like it to remain maintained, please [open an issue](https://github.com/mrhoeve/wrp/issues/new) before the repository is archived and tell us about your use case. The issue tracker becomes read-only after archiving.
