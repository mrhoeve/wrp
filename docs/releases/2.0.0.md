## Breaking change

WRP now returns the effective column names from the current ODS document as JSON property names in `GET /registerdata`. Consumers that depend on the legacy hard-coded property names must update their mapping. Use `GET /metadata` to discover the exact active `columnHeaders`.

The REST paths, request parameters, callback behavior, and process-health semantics remain unchanged. The parser accepts the columns that are actually present in the source ODS, including added, removed, reordered, duplicate, and empty headers.

## Modernization highlights

- Java 21, Kotlin 2.3, and Spring Boot 4.1 runtime
- safer streaming ODS parsing with configurable resource limits
- resilient register refresh that preserves the last valid dataset
- expanded automated unit, integration, concurrency, and REST-contract testing
- non-root container with automated vulnerability scanning, SBOM, and provenance
- `GET /version` with background update detection
